## 新版应删除

1. 任务 `DRAFT`、`PUBLISHED`、`ARCHIVED` 生命周期及页面状态列。
2. 发布、归档、再次发布、已发布不可编辑、发布版本及相关确认弹窗和说明。
3. “保存草稿”“任务草稿已创建”等草稿文案。
4. 地图列表中的 PCD 文件名、编码、二维预览状态列。
5. 地图详情“文件与配准”技术信息，包括文件大小、编码、坐标系、分辨率、原点、关联任务数、更新时间。
6. 账号菜单的“查看运行状态”、`/runtime` 页面和顶部服务连接指示。
7. 人设列表的系统类型、更新时间列，以及默认人设的列表项。
8. Agent 面向用户的 `v1` 等版本展示。

## 新版应保留或补齐

1. 导览任务中的语音人设、点位和路径任务、语音播报、语音问答、技能调用。
2. 人设的音色、提示词、MCP 插件关联、预置技能、自定义技能和手势编排。
3. MCP 插件完整 CRUD、工具刷新、认证信息与自定义请求头。
4. 任务详情地图画布和点位可视化。
5. Agent 的本地地图页、上传地图、任务与地图联动下载/清理、删除确认、Toast、无网络态和自动更新。
6. 登录/注册、语言切换、退出登录。

## 已确认的保留项

1. 地图仍被任务引用时禁止删除：保留。
2. PCD、PNG 和配准 JSON：暂时保留为底层上传合同，前台不展示技术细节；后续可替换为 zip 上传。
3. Agent 只负责与云端导览后台进行资源同步，不处理机器人实际执行流程协议。

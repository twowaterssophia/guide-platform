# 页面、路由与用户流程清单

状态：完成（阶段 0.3）

本文记录旧版可观察行为、新版覆盖情况和迁移依赖。状态含义：

- `已接入`：新版页面已经通过 API 持久化或读取真实业务数据。
- `界面占位`：页面或交互存在，但不能完成业务操作。
- `仅旧版`：只有旧版静态原型提供该行为。
- `未开始`：目标行为尚未创建。

## 迁移验收的行为参照

迁移时必须保留或有意替代以下旧版细节，并在验收记录中注明差异：

- 地图被任务引用时，删除需要拒绝或明确处理引用；不能静默造成无地图任务。
- 删除插件后，所有使用该插件的人设都解除绑定。
- 删除人设后，引用它的任务回退到系统默认人设。
- 任务点位顺序决定路径顺序；重排或删除点位必须同步路径。
- 路径动作不能添加技能动作；点位动作可添加语音、技能和交互动作。
- 语音动作必须有播报文本，技能动作必须选择技能；交互动作当前允许空 `prompt`。
- 所有有未保存草稿的离开动作都有放弃确认；列表行可通过 Enter 或 Space 打开。

# 迁移验收清单

状态：完成（阶段 0.6）

验收以可观察的业务结果为准，不以“页面可以打开”代替完成。每个业务域完成时，
需要记录环境、测试数据、请求结果、截图或自动化测试结果，以及与旧版的有意差异。

## 通用检查

每个迁移页面和 API 都应验证：

- 默认、加载、空、错误、权限不足和网络失败状态。
- 表单必填项、格式校验、服务端错误映射和首个错误字段聚焦。
- 取消、返回、浏览器后退、Esc、点击外部和未保存内容放弃确认。
- 删除确认和被引用资源的保护性错误。
- Enter/Space 表格行操作、Tab 焦点顺序、可见焦点和屏幕阅读器名称。
- 桌面与窄屏下的文本换行、滚动、弹窗和操作列可用性。
- 请求完成后数据刷新、并发冲突提示和刷新后数据持久化。
- API 不泄露插件凭据或其它敏感配置。

## P0 端到端流程

### A. 创建和管理地图

当前状态：本地迁移闭环已通过；生产容量、对象存储签名 URL 和真实身份仍待联调。

| 检查 | 通过条件 |
| --- | --- |
| 上传 | `.pcd + .png + .json` 三件套和名称可创建资产；无名称、缺文件、错误类型、PNG 尺寸不一致和超限大小有明确错误。 |
| 列表与详情 | 新地图在列表和详情中可见，显示 PCD 元数据、PNG 预览和配准信息；旧兼容数据明确显示不可预览。 |
| 改名 | 改名后任务显示名称同步来自地图关系，而不是保存旧的 `mapName` 副本。 |
| 删除保护 | 被任务引用的地图不能被删除，并返回 `RESOURCE_IN_USE`。 |
| 文件安全 | storage key 由服务端生成，API 不暴露绝对路径；预览流按当前账号隔离。 |

### B. 创建、保存和编辑导览任务

| 检查 | 通过条件 |
| --- | --- |
| 基本信息 | 任务名称和服务端地图选择为必填；不能引用其他用户地图。 |
| 点位 | 可新增、编辑、删除、拖动排序、调整坐标和朝向；保存后顺序及数值不变。 |
| 路径 | 路径由点位顺序生成；删除/重排点位后无孤立路径。 |
| 动作 | 点位允许语音、技能、交互；路径不允许技能；动作顺序可保存。 |
| 动作校验 | 语音必须有播报文本，技能必须选择可见技能，交互 `prompt` 按最终模型保存。 |
| 人设 | 有语音或交互动作时可选择可见人设；删除人设后的回退规则可解释且可测试。 |
| 草稿 | 保存草稿后刷新、重新登录或重新打开详情仍显示相同内容。 |
| 编辑并发 | 两个编辑会话修改同一任务时，后提交方收到版本冲突，不覆盖先提交方。 |
| 删除 | 删除确认后任务不可再从列表、详情或 Agent 下载列表读取。 |

### C. 发布任务与 Agent 下载

| 检查 | 通过条件 |
| --- | --- |
| 发布校验 | 缺少地图、点位、必填动作内容或不可用依赖时不可发布，并指出原因。 |
| 版本 | 每次发布产生递增版本；草稿修改不改变已下载的发布版本。 |
| Agent 列表 | 设备只能看到有权限的已发布任务，并明确显示待下载、已下载或可更新。 |
| 下载 | 下载包对应已发布版本，包含所需地图、点位、路径、动作、人设和依赖清单。 |
| 下载记录 | 成功下载后写入或更新 `AgentDownload`；删除本地包后同步记录移除。 |
| 更新 | 新版发布后，已下载旧版本设备显示可更新，不会静默替换运行中任务。 |

## P1 管理流程

### 人设

| 检查 | 通过条件 |
| --- | --- |
| CRUD | 名称、音色和提示词保存后可在列表、详情和任务编辑中一致读取。 |
| 插件绑定 | 只能绑定当前用户可见插件；删除插件后人设关联被解除。 |
| 自定义技能 | 来源、说明和示例均能持久化；未解决 Prisma 模型前不得开放保存。 |
| 系统默认 | 系统默认人设不能被删除，且任务回退行为已覆盖。 |

### MCP 插件和技能

| 检查 | 通过条件 |
| --- | --- |
| 认证校验 | none/bearer/API key/basic 的必需字段正确校验。 |
| 凭据安全 | 创建后 API、列表、详情和日志均不回传 secret。 |
| 请求头 | 仅接受 JSON object，非法 JSON 不保存。 |
| 工具刷新 | 刷新成功更新工具和时间；失败保留旧工具并展示可行动错误。 |
| 技能目录 | 按 source/兼容性显示当前身份可见技能，且无法选择不兼容技能。 |

## 新旧行为对照

以下旧版行为需要在迁移验收时逐项标记为“保留”“有意替代”或“废弃并说明原因”：

| 旧版行为 | 目标处理 |
| --- | --- |
| `localStorage` 自动持久化 | 替换为 API/数据库持久化；只保留临时未保存编辑状态。 |
| 放弃表单时确认 | 保留。 |
| 表格行键盘打开详情 | 保留。 |
| 删除人设后任务回退默认人设 | 保留或以 API 明确拒绝替代，二者择一并记录。 |
| 删除插件后解除人设绑定 | 保留。 |
| 路径动作禁止技能 | 保留。 |
| 旧版静态 Agent 的执行按钮 | 阶段 5 前仅作为交互参照，不宣称已接入机器人。 |

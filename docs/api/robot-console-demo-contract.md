# 机器人远程监控 Demo 契约

## 1. 范围

机器人列表和详情页用于验证远程监控、导览任务配置与运行控制的前端交互。机器人连接、电量、位置、任务下发、Agent 状态、定位和执行进度均为浏览器端模拟状态；视频使用本地演示画面，对讲只模拟接管状态，不请求浏览器麦克风，也不建立真实音视频链路。页面不调用机器人生产接口。

平台导览任务和地图沿用现有前端 API。任务列表请求不可用时，页面使用内置 Demo 任务，保证本地演示可闭环。

## 2. 数据模型

机器人数据 schema 定义在 `packages/contracts/src/index.ts`，Mock Adapter 位于 `apps/console/src/features/robots/robot-console-api.ts`。

- `RobotSummary`：机器人 ID、名称、连接状态、电量和已下发任务数。
- `RobotDetail`：机器人摘要、导览 Agent 状态、视频可用状态和运行时状态。
- `RobotTaskSummary`：机器人已接收的导览任务、地图和任务版本。
- `RobotRuntimeState`：当前任务 ID、地图坐标与朝向、定位状态与定位请求（模式、目标坐标、发起时间）、执行状态、流程索引、接管音色、接管状态、音量和静音状态。旧数据缺少朝向时默认为 `0`。
- `SelectedTourTask`：所选 `TourTaskDetail` 及关联的 `MapAssetDetail`；Demo 内置地图可为空，页面会按任务坐标绘制示意底图。

Demo 状态按机器人 ID 存入 `localStorage`，键为 `guide.robot-console-demo.v2`。刷新页面后恢复；清除该键可恢复初始状态。

默认语音音量为 60%。兼容旧版 Demo 数据时，仅将未带音量默认版本标记的 72% 更新为 60%；其他音量及任务状态保留，之后用户主动设置的 72% 也会正常保存。

## 3. 交互和状态规则

机器人列表仅显示已连接的机器人，不显示连接状态列；表格保留机器人、电量、导览任务和操作四列，“下发任务”和“实时监控”为图标按钮，悬停显示操作名称。整行点击或行聚焦后按 Enter / 空格进入实时监控；下发按钮单独打开弹窗，不触发行跳转。全部断连时显示“暂无已连接的机器人”。页面、提示和替代文字不展示模拟、演示或 Mock 标记，内部仍沿用现有 Demo Adapter 与存储键。

1. 初始机器人已连接、未启动导览 Agent、没有已下发任务。启动 Agent 是用户主动操作，当前 Demo 只提供一个导览 Agent。未启动时右侧只显示居中的“启动导览 Agent 后，即可进行导览相关操控”提示与“启动导览 Agent”按钮，不显示占位图、任务列表、添加任务或地图占位。
2. 机器人任务列表只展示已下发任务。Agent 已启动但机器人没有任务时，右侧仅显示居中的“当前机器人上没有导览任务”和“下发任务”按钮；不显示空任务列表及地图占位，删除最后一个任务后也回到此状态。可从机器人列表或详情页打开下发对话框，下发成功后任务才会出现在机器人任务列表中。若平台任务版本变化，机器人上的旧版本不可选择，需重新下发。
3. 右侧先展示导览任务列表，选择任务后进入详情，隐藏列表并加载关联地图、路线、点位和流程；可返回列表，再次进入当前任务时保留执行状态。第一个点位是导览起点。左右标题水平对齐，摄像头与地图均为 16:9。地图支持拖动、滚轮缩放、右键旋转和视图重置，工具按钮悬浮在右上角，机器人及点位均显示朝向箭头。
4. 不提供远程手动移动入口或移动命令。未定位时提供“一键定位”和“选点定位”，定位状态统一显示在地图下方。一键定位提示“机器人定位中，请让机器人站在路线起点附近”；选点定位通过地图点击指定位置，可确定或取消，确定后提示“定位中，请保持机器人在所选点位附近”。定位成功显示“定位正常”和“重新定位”；超过 1 分钟未成功则显示“定位失败”，可重新定位或选点定位。Demo 在约 2.2 秒后返回目标位置，不校验现场距离或朝向；现场校验留给后续设备定位接口。定位成功后才能开始导览。
5. 导览执行中或暂停时，切换任务、添加和删除机器人任务均不可用。运行态按 Demo 流程自动推进；用户也可暂停、继续、下一步或结束。
6. 实时语音控制提供男声和女声选择，默认音量为 60%，通过“开始人工接管”和“结束人工接管”切换接管状态。“静音”切换按钮放在“实时画面”标题旁；静音选中时使用主题主色，再次点击取消，静音状态刷新后保留，与机器人语音音量独立。接管期间自动播报显示为暂停，导览路线继续推进；该状态不产生真实音频或机器人播报。
7. 机器人断连时，操作入口禁用；正在执行的导览转为暂停，正在进行的定位转为失败，接管状态结束。重新连接后任务和地图仍保留，用户可以检查状态后继续。

## 4. 前端 API

所有机器人页面业务状态通过 `RobotConsoleApi` 访问，不在组件中直接读写 `localStorage`。

| 方法 | 作用 |
| --- | --- |
| `listRobots()` / `getRobot(robotId)` | 查询 Demo 机器人列表和详情 |
| `enterTourAgent(robotId)` | 手动启动唯一的导览 Agent |
| `listPlatformTasks()` | 读取平台任务；失败时回退到内置 Demo 任务 |
| `listRobotTasks(robotId)` | 读取该机器人已下发任务 |
| `dispatchTasks(robotId, taskIds)` | 模拟任务及资源下发，并保存任务版本 |
| `selectTask(robotId, taskId)` / `getSelectedTask(robotId)` | 选择机器人任务并恢复关联地图快照 |
| `startLocalization(robotId, target?)` | 发起定位；省略目标时使用路线起点，否则使用地图所选位置 |
| `updateRuntime(robotId, patch)` | 更新定位、导览执行和语音接管状态 |
| `deleteRobotTask(robotId, taskId)` | 从机器人 Demo 列表移除任务 |
| `toggleConnection(robotId)` | 切换模拟连接状态 |
| `resetDemo()` | 删除机器人 Demo 存储 |

## 5. 后续生产接口边界

以下仅用于未来接入讨论，不表示这些接口已存在。服务端需要重新校验连接状态、Agent 状态、任务下发版本、定位结果和执行状态。

| 前端能力 | 后端候选能力 |
| --- | --- |
| 机器人列表及状态 | `GET /robots`、`GET /robots/:robotId`，并确认轮询或实时状态推送协议 |
| 启动导览 Agent | `POST /robots/:robotId/agent` |
| 任务列表和下发 | 复用 `GET /tour-tasks`；`POST /robots/:robotId/tour-tasks` 触发下发并返回设备回执/进度 |
| 选择已下发任务 | `GET /robots/:robotId/tour-tasks/:taskId` 或以任务版本为条件的选择命令 |
| 现场放置后的定位 | `POST /robots/:robotId/localization`；此页不提供远程手动移动接口 |
| 导览开始和控制 | `POST /robots/:robotId/executions`，以及执行实例的暂停、继续、下一步和结束命令 |
| 实时语音接管 | 建立实时媒体会话与控制信令；服务端/机器人需支持男声、女声音色及接管期间的自动播报策略 |
| 摄像头画面 | 由设备和媒体服务提供可鉴权的视频播放地址及断连状态 |

## 6. 验收

- 机器人列表只显示已连接设备，断连后返回列表即移除该设备；全部断连时显示空状态。列表没有连接状态列或演示标识，详情页提示也没有演示字样。操作使用带悬停提示的图标，整行进入监控且下发操作不会触发行跳转。
- 未启动 Agent 时右侧仅有引导文字和“启动导览 Agent”按钮；顶部不显示 Agent 状态或 Demo 副标题，设备名为 `T2 V1.2 - 999`。
- 从未启动 Agent、无任务的状态可完成“启动 Agent → 下发任务 → 选择任务 → 加载地图”。
- Agent 已启动但无任务时，右侧只显示指定提示和一个“下发任务”按钮，删除最后一个任务后恢复该状态。
- 默认语音音量为 60%，旧版默认音量兼容更新且保留任务；静音按钮可切换选中颜色并恢复保存的状态。
- 任务列表与详情为切换关系，可返回列表；地图与摄像头占位对称，地图与机器人标记展示朝向。
- 一键定位、选点定位的确定与取消、正常状态及超时失败均可闭环；定位请求刷新后恢复，成功定位不校验朝向。
- 页面没有远程手动移动入口；导览开始后自动推进，暂停、继续、下一步和结束均可操作。
- 接管状态下路线继续推进，结束接管后可恢复自动播报状态；页面不会申请真实麦克风权限。
- 刷新后已下发任务、所选地图和运行状态可以恢复；断连状态下不允许发送控制操作。
- `e2e/console/robot-console.spec.ts` 覆盖桌面和移动视口的完整主要流程。

配色遵循 `docs/design-audit/design-spec.md` 第 3 节，所有机器人页颜色复用共享 Token，绿色只用于成功或正常状态。

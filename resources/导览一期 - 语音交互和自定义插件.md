# 导览一期 \- 语音交互和自定义插件

# 背景 / 问题

在导览场景下，机器人需要基于客户知识库，自主和用户进行语音互动，如在展厅回答游客问题，在地铁回答乘客问询等。语音交互内容可能需要调用三方接口，如客户自研知识库接口。

# 目标

1. 支持在导览任务中进行语音交互，包括在固定点位和移动中支持语音交互

2. 支持配置语音交互人设，如设置音色、提示词等

3. 支持语音交互接入 MCP 插件

    - 接入后，客户可以自由接入任意 API；在满足北京地铁需求的同时，可作为通用的二次开发方案，竞品平台（智元灵心）亦采用此设计

## 导览后台 \- MCP 插件管理

|功能描述|界面示意图 / 流程图|
|---|---|
|**无人设时展示占位图**<br>- 展示「添加插件」按钮、占位图、提示文案||
|**添加插件**<br>- 点击弹出弹窗：<br>    - 名称：文本<br>    - 描述：文本，说明信息“描述插件主要功能和使用场景，帮助模型更好判断何时调用”<br>    - 识别示例：文本，说明信息“列举具体的插件调用场景，如当用户询问什么时，应当调用本插件，当用户询问什么时，不应当调用插件”<br>    - 认证方式：单选：<br>        - 不需要认证：默认选项<br>        - Bearer Token（令牌）<br>        - API Key（密钥）<br>        - Basic Auth（用户名和密码）<br>    - 认证信息：选择任意认证方式后出现<br>        - 如果选择 Bearer Token，出现输入框 token<br>        - API Key，出现两个输入框：请求头名称，API Key<br>        - Basic Auth，出现两个输入框：用户名，密码<br>    - 自定义请求头：选填，placeholder:"请输入 JSON 格式的请求头，如：\{"X\-Custom\-Header":"value","X\-Another\-Header":"value"\}”<br>**保存插件**<br>- 点击「保存」后，进行 MCP 插件的 initialize 流程，并获取 tools 列表<br>    - 成功获取到 tools 列表：toast 成功提示“添加成功”<br>    - 未成功获取到 tools 列表：toast 错误提示“未获取到工具列表”||
|**查看插件列表**<br>- 展示所有插件，展示信息包括：<br>    - 插件名称<br>    - 工具数量<br>    - 工具名称：所有工具展示为标签，如果超出列宽，则 hover 出现更多<br>    - 创建时间<br>    - 最后刷新时间：默认是创建时间，当进行“刷新”操作后，更新时间<br>    - 按钮：「刷新」「编辑」「···」按钮<br>- 按创建时间倒序排列||
|**刷新插件**<br>- 点击重新对插件进行初始化和获取工具，更新工具数量、工具名称与最后刷新时间||
|**编辑插件**<br>- 点击编辑后，重新打开弹窗，可编辑信息||
|**删除插件**<br>- 点击插件列表页右侧「···」弹出二次确认弹窗，确认则删除人设||

## 导览后台 \- 在导览任务中增加语音交互

|功能描述|界面示意图 / 流程图|
|---|---|
|**新建导览任务时，支持在路径上设置任务**<br>- 标题改为“设置任务”<br>- 结构改为：<br>    - 抵达\{点位1\}后<br>    - 从\{点位1\}到\{点位2\}途中<br>    - 抵达\{点位2\}后<br>    - 从\{点位2\}到\{点位3\}途中<br>    - 以此类推<br>- 点位和在路径标题分别有不同的 icon 以区分示意||
|**抵达点位后，新增「语音交互」类型的任务**<br>- 点击“添加任务”，出现「语音交互」选项，可添加至点位任务列表||
|**在路径上，增加「语音交互」和「语音播报」任务**<br>- 点击“添加任务”，出现「语音播报」和「语音交互」选项<br>    - 选择「语音播报」后，添加至点位任务列表，可输入讲解词<br>    - 选择「语音交互」后，添加至点位任务列表||
|**选择语音人设**<br>- 在任意点位或路径，选择了「语音播报」或「语音交互」任务后，在设置点位任务下方，出现「选择语音人设」选项<br>- 在下拉菜单中，出现「默认」和用户已配置的所有人设名称||

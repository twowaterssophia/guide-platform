# 导览一期 \- 支持机器人说话时调用技能

# 背景 / 问题

为了使机器人在语音交互时看起来更拟人，我们希望机器人在说话时可以自主做一些手势动作。

未来，我们希望支持二开公司或者客户添加自己的动作，并支持大模型自主调用。

# 目标

- 支持用户为人设配置技能，包括预置技能（P0，不走技能库）和自定义技能（P1，走技能库）

- 支持机器人在语音播报和语音交互时，自主调用技能
